## できること

- **選手** … 名前（ひらがなでも可）・都道府県で検索。鹿児島は先頭に⭐チップ。
  種目行に**組・レーンと開始予定時刻**が出て、タップすると組・レーン画面へジャンプ。
- **種目** … 競技No.ごとに出場者を組・レーン順で一覧。
- **日程** … 全106プログラムを日別に。**開始予定時刻**つきで、表彰・予選終了・決勝終了・総合表彰式も並ぶ。
- **リレー** … 種目ごとの出場チーム（都道府県）と組・レーン。
- **組・レーン** … レースを選ぶと10レーンを縦に並べて表示。**確定値**（予想ではない）。
- **大会情報** … 期日・会場・種別の年齢区分・注意書き。
